# RottenPotatoes - Movie Catalog App

## Overview
This is a simple Ruby on Rails 4.2 application for cataloging movies. It allows users to:
- Add new movies
- View movie details
- Edit movie information
- Delete movies

## Setup Instructions
1. Clone this repository
2. Run `bundle install`
3. Run `rake db:migrate`
4. Run `rake db:seed`
5. Start the server using `rails server`
6. Open `http://localhost:3000/movies` in a browser

## Technologies
- Ruby 2.7.8
- Rails 4.2.11
- SQLite3
- Bootstrap (for UI styling)
